# Synthetic-Benchmark-Dataset-of-an-Avionic-Main-Fuel-Pump-System-for-Data-Driven-Fault-Diagnosis
Synthetic multivariate time-series from a high-fidelity Simulink/Simscape model of an aircraft main fuel-pump system with explicit fault injection. Includes healthy and faulty modes with component-level labels for benchmarking anomaly detection and diagnosis in CPS.
